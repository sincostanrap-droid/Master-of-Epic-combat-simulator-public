# Master of Epic 戦闘シミュレーター

Master of Epic の非公式計算ツールです。ブラウザ上で技・魔法、装備、Buffの条件を入力し、ダメージ・回復量・能力補正・持続時間などを確認できます。

現在の版：**v1.24.25**

[ブラウザ版](https://sincostanrap-droid.github.io/Master-of-Epic-combat-simulator-public/)

## 主な機能

- 戦闘試行α：技・魔法の検索、スキル・魔力・対象条件からの効果計算
- 物理ダメージ計算、アタックDPS、追撃の試算
- 装備・Buffカタログ、候補登録、競合の確認、構成の最適化
- スキルシミュレータ、戦闘ログ解析、構成比較と共有表示
- JSON・TSVによる保存／読込、共有URLによる構成の復元

計算できない効果や必要条件は画面に表示します。1回量、平均値、条件付き合計は別の値です。セット マイン／クロスファイアー ボムの爆発候補選択は実測待ちで、完全対応ではありません。ゲーム内の成否や戦闘状態をすべて再現するものではありません。

HP・MP・STは整数、その他は原則小数点第一位まで表示します。表示の丸めは内部計算の精度を変更しません。

## 保存データについて

登録した構成は利用中のブラウザに保存されます。更新前や別の環境への移行前には「保存・読込」からJSONを出力してください。

ローカル版と公開版では保存領域が異なります。自動移行・自動削除は行いません。移行するときは、移行先の構成も先にバックアップしてからJSONを読み込んでください。共有URLには構成が含まれるので、共有前に内容を確認してください。

## ローカルでの確認

Python 3.11以上で、選別済みファイルのみを新しいフォルダに組み立てます。

```text
python tools/build-pages.py --output .local-preview/my-pages-check
python -m http.server 8000 --bind 127.0.0.1 --directory .local-preview/my-pages-check
```

ブラウザで `http://127.0.0.1:8000/` を開きます。出力先が既にある場合は上書きせず停止するので、別名を指定してください。ファイルの直接オープンではデータ読込やWorkerが制限されます。

## 公開・保守

[公開版の更新・公開手順](release/README.md)に、更新前の保全、掲載ファイルの確認、限定検証、手動公開、不具合時の戻し方をまとめています。GitHub Pagesには `release/web-files.txt` に列挙したファイルだけを配信し、`release/web-hashes.json` で内容を検証します。実行に必要な生成データは含め、解析資料・生データ・個人の登録構成は含めません。

外部DB取得用のCloudflare Workerは別サービスです。現在の画面にはURL取得用入力欄がありません。装備カタログの通常利用は同梱データを使います。
